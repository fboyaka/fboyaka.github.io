## Project Description
This is my personal website. The goal is to create a trove of notes and projects to reference while also mapping out what I've learned. These projects are also intended to be MVPs (Minimum Viable Products) where the functionality and scope is reigned in to prevent feature creep. Results should be visible within a week and goals should take two days at worst.<br>
Projects listed here will either be fully functional on the site or include details about the project which should be very easy to set up. As someone who dislikes projects which require a lot of set up I'll aim to avoid that when creating/designing my own.<br>

## Project Workflow
This website will keep track of my daily and weekly features that I have developed.
